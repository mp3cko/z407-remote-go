    Troubleshooting
    • The speakers accept one Bluetooth LE controller at a time. If a phone is connected to them, disconnect it first.
    • Page not loading from your phone? Check the firewall and VPN settings on the computer running the app, and make sure both devices are on the same network.
    • Web address not working? A VPN or virtual machine may be advertising a different network interface; try another address from the list.
